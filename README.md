
# CampusFest OS — College Event Planning & Review Platform

## About the Project

CampusFest OS is a web-based platform designed to simplify college event planning, coordination, budgeting, and post-event evaluation. It provides a central workspace where student organisers, faculty coordinators, and finance teams can manage event information and review outcomes.

The platform helps teams organise event activities, track expenses, record incidents, and use feedback to improve future college events.

## Problem Statement

College festivals and technical events involve multiple teams, schedules, budgets, sponsors, and activities. Managing these details across separate documents and communication channels can lead to confusion, missed deadlines, budget overruns, and repeated mistakes.

CampusFest OS addresses these challenges by bringing essential event management and review activities into one organised platform.

## Objectives

- Simplify college event planning and coordination.
- Maintain event schedules, milestones, and responsibilities.
- Track planned and actual expenses.
- Record sponsorship contributions and financial information.
- Document event-day incidents and their resolutions.
- Collect post-event feedback and recommendations.
- Support continuous improvement for future events.

## Key Features

### 1. Post-Event Review
Organise event feedback, attendance information, achievements, challenges, and recommendations for future editions.

### 2. Next-Edition Planning
Use lessons from previous events to prepare timelines, milestones, approvals, and logistics plans.

### 3. Budget and Financial Tracking
Maintain expense records, compare planned costs with actual spending, and review sponsorship contributions.

### 4. Incident Management
Record event-related issues, document immediate responses, and identify preventive measures.

### 5. AI-Assisted Recommendations
The optional AI integration can help summarise event information and suggest improvements. Recommendations should be reviewed by organisers before implementation.

### 6. Event Reporting
Present event information in an organised format that can be reviewed and printed as an event dossier.

## How the Platform Works

1. Create or select an event.
2. Review event details and plan activities.
3. Track budgets, expenses, and sponsorships.
4. Record incidents and their resolutions.
5. Review event outcomes and recommendations.
6. Prepare information for the next edition.

## Installation and Setup

### Prerequisites

- Node.js and npm
- A code editor such as Visual Studio Code
- A Google Gemini API key, if using the live AI features

### Steps

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Install the required dependencies using the package manager and scripts defined in the project.
4. Configure the required environment variables for the backend and AI integration.
5. Start the frontend and backend using the scripts specified in their respective `package.json` files.
6. Open the local development URL shown in the terminal.

**Note:** Exact commands may vary depending on the folder structure and scripts included in the downloaded project.
